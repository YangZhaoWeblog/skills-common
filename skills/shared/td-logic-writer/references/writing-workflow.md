# Writing Workflow

## 1. 先定文章契约

先读当前文、用户修改、截图、链接和参考样本。真源优先级通常是：用户刚确认的成品 / 当前文件 > 旧版本 > 历史讨论。

写作前在内部回答：

- 读者是谁，真正要做什么判断？
- 默认选择是什么？什么新事实会改变它？
- 哪些内容不属于本文，应该链接、留在来源或另写？

无法写出默认选择或根定义的文章，通常还在资料收集或概念澄清阶段，不急着成文。

长任务维护最小纠正记录：

| 纠正对象 | 已确认写法 | 影响范围 |
| --- | --- | --- |
| 术语 / 事实 / 范围 / 风格 / 流程 | 新约束 | 必须同步的章节或产物 |

这张表用于写作记忆，不默认进入正文。

## 2. 按任务选骨架

| 类型 | 默认骨架 |
| --- | --- |
| 概念边界 | 根定义 → 边界与混淆对象 → 区别改变什么使用判断 |
| 项目认知 | 负责什么 → 关键关系与边界 → 日常判断与自检 |
| 判断标准 | 判断对象 → 条件与反例 → 采取什么动作 |
| 证据型决策 | 默认选择 → 改变选择的条件 → 候选矩阵 → 执行 / 停止条件 → 来源 |

骨架服务读者的认知路径，不强制背景先行，也不为了完整感补齐所有章节。

## 3. 建立判断账本

证据型决策、重写或复杂文章先在内部维护：

| 关键判断 | 主载体 | 改变选择的条件 | 必要证据 | 正文外归属 |
| --- | --- | --- | --- | --- |
| 一条可行动结论 | 开场 / 表格 / 行动门禁之一 | 何时例外 | 一条最短证据链 | 来源、附录或关联笔记 |

- 一条判断只能有一个主载体。
- 同一判断在其他位置出现，必须新增条件、例外、证据或动作。
- 有明确主笔记且读者可跳转时，通用规则只由主笔记承担；其他文章链接它，只保留本篇不可缺的最短提醒。

## 4. 放置信息，而不是堆信息

| 信息 | 首选位置 |
| --- | --- |
| 默认选择、边界、后果 | 开场短段或章节中心句 |
| 候选比较、准入门禁、排序 | 表格 |
| 层级、关系、流程、映射 | 图 |
| 改变选择的关键证据 | 判断旁的一两句，附来源 |
| 不改变结论的样本细节、注册信息、长争论、历史问答 | 来源、附录或关联笔记 |

图或表已经表达的信息，正文只写理由、例外和后果。没有稳定比较维度时，不用表；没有空间关系时，不用图。

保留事实不等于保留原句。对每条事实判断它属于：

- **决定性证据**：会改变候选、门槛或停止条件，留在判断旁。
- **可追溯细节**：支撑来源但不改变选择，留在表格注释或来源说明。
- **背景记录**：留在附录或关联笔记。

两个以上并列段落若导向同一动作，优先合成一个决策矩阵；表格形成后删掉逐项复述。压缩时保留证据的范围与力度，不能把“本次纳入”“某研究”扩大成“全部现有”，也不能把“不能支持”写强成“证明”或“排除”。

## 5. 无损压缩

按以下顺序重写：

1. 标记每段承担的角色：判断、条件、证据、例外、动作或背景。
2. 同一角色在重复同一判断时，合并到主载体。
3. 反面说明只保留能排除真实错误路径的；不要连续用“不是 / 不等于 / 不能”改写同一结论。
4. 删除被表、图或链接完整覆盖的展开文字，必要时压成一行锚点。
5. 背景只保留到足以理解下一步判断为止。

对“精炼、去重、重写”任务，结束前在内部核对：每条关键判断原来有哪些载体，现已合并、移位或删除了什么。若只调整标题和语序，说明压缩尚未发生。

不设机械字数目标。删掉后无法解释“为什么这样判断”的证据，应移位而不是删除。

## 6. 事实与主观边界

- 技术 / 项目事实：验证现行代码、协议、数据、配置和当前文档，区分旧事实与现状。
- 健康 / 医美 / 财务：标明来源、不确定性和个人约束，不装成专业诊断。
- 情感 / 人生：区分外部观点、事实观察和个人策略。
- 影响核心判断但无法验证的内容，先停下来查或问；不影响骨架的内容标为假设或待验证。

## 7. 用成品反哺

- 正向样本：用户或评审最终认可的结构和载体。
- 负向样本：用户删掉、压缩或明确反对的内容，识别“看似完整但降低判断速度”的模式。

只把跨主题规律写回 Skill；一次性事实和偏好留在项目记录。
