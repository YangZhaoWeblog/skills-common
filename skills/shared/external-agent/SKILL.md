# 外部 Agent

主控调用原生 CLI；任务与角色由调用方指定，**不依赖 Harness 或固定角色**。受派执行者完成任务，不因读取本 Skill 再次派发自己。

## 一、派发

1. **取得参数**：从用户指令或调用方配置读取 **executor（命令入口）、model（平台模型 ID）、effort**，逐字段以本次明确指令优先。齐全则执行，缺项一次询问、补齐前不启动；medium 只能推荐。无需角色文件或用户级配置，不自动读取全局默认。
2. **核对能力**：只读选定平台说明：[Codex](references/codex.md)、[Claude Code](references/claude.md)、[CodeBuddy](references/codebuddy.md)。定位命令，首次使用或升级时核对帮助、包装器转发和能力；模型 ID 不跨平台照搬，不支持时报告，不静默换入口、模型或档位。
3. **准备任务**：包含目标、目录、职责、规则与批准依据、读写范围、验收条件和交付位置。有角色文件则读取配置与正文，否则使用本次任务说明；配置显式转为 CLI 参数，职责加入任务。executor 是主控约定字段，不依赖 CLI 自动识别。项目升档策略仅作用于指定角色，本次明确档位优先。
4. **主控核对权限**：依据任务与已有授权确定目录、读写范围和 CLI 设置，检查实际工具能力与冲突写入者，不逐项询问用户。外部 CLI 不继承主控沙箱，Prompt 不提供权限隔离，不默认绕过权限；越权或无法自行解决的严重问题才交用户决定。

## 二、执行与交付

**日志留本机，默认只读终态、摘要和必要错误片段。** 任务文本、完整 stdout/stderr 存仓库外私有目录（目录 0700、文件 0600）；记录去凭据命令、目录、请求模型/effort、进程句柄、原生会话 ID、日志路径和退出状态。未经运行信息证实的模型/档位只标为请求值，真实任务、账号及内部配置不进入共享 Skill。

使用执行工具的后台句柄和等待接口跟进；无输出时检查进程与日志，不视为结束。达到任务时限或用户要求停止时，按下一节处理。

**成功终态与正常退出只证明调用成功，产物仍须验收。** 核对 stderr、工具拒绝及真实交付，区分警告和失败，不凭 exit 0 或模型自述判定。按任务条件验收；需要独立验证或审阅时提供原始依据与产物，不转交完整执行对话。交回结果、产物位置、实际检查、未决问题与恢复信息。

## 三、恢复与停止

**同任务使用原 CLI、目录和明确会话 ID 恢复。** 主控先检查部分产物及用户后续修改，确定剩余工作，再核对参数与权限。恢复失败就报告，不猜最近会话，也不用新建或 fork 代替；新任务、独立验证与审阅另开上下文。

前台调用通过持有的执行句柄停止并等待；原生后台任务使用对应停止命令。仅操作本次拥有且身份已核对的进程，并检查相关子进程。**信号发出不等于已停止**；无法确认则标为未知，暂停冲突写入并报告。不为此新增常驻服务或调度脚本。

## 四、可选保存

每次未固化调用结束后，用一句话建议保存为角色 Agent；已固化或用户在本次会话拒绝过的不再提醒。**拒绝则不写配置、入口或拒绝记录**；跨会话只沿用已获准保存的偏好，不承诺自动记住拒绝。

用户愿意保存时，先展示职责、executor/model/effort、文件位置及入口改动，**批准后配置与入口一起写**。复用已有角色文件和项目入口；无 Harness 时只提出轻量配置和入口，不强建工作流。入口明确何时读取配置、由主控按参数调用本 Skill，写后核对引用。不保存则两者都不写；保存不授予后续业务写权限，也不自动改变其他角色路由。
