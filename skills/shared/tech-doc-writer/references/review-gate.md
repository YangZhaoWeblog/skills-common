# 技术文档 Review Gate

非平凡文档使用独立 reviewer；reviewer 不改文件。

## 最小 Review 包

- 文档目标、主要读者和组间同步对象。
- 当前真源与优先级。
- 已确认术语、事实、范围和样式。
- 变更账本或证据清单。
- 用户认可的参考成品；没有则明确标无。
- 文档路径和对应 checklist。

reviewer 只读 Review 包、目标文档、必要事实源和 checklist；不读完整聊天或 writer 中间推理。

| 结论 | 处理 |
| --- | --- |
| pass | 可交付 |
| minor | 修复后自审 |
| structural | 回到骨架 |
| coverage | 补齐矩阵、定义或流程 |
| factual | 停止并查证 |
| blocked | 向用户确认目标、边界或真源 |

最多复审一次。第二轮仍为 structural、coverage、factual 或 blocked 时停止硬改，报告卡点。
