# 技术文档 Review Gate

非平凡文档使用独立 reviewer；reviewer 不改文件。

## 最小 Review 包

- 文档目标、主要读者和组间同步对象。
- 当前真源与优先级。
- 已确认术语、事实、范围和样式。
- 变更账本或证据清单。
- 用户认可的参考成品；没有则明确标无。
- 文档路径和对应 checklist。

reviewer 只读 Review 包、目标文档、必要事实源和 checklist；不读完整聊天或 writer 中间推理。

| 结论 | 处理 |
| --- | --- |
| pass | 可交付 |
| minor | 修复后由独立 reviewer 复核最终候选 |
| structural | 回到骨架 |
| coverage | 补齐矩阵、定义或流程 |
| factual | 停止并查证 |
| blocked | 向用户确认目标、边界或真源 |

复审按本次修改任务记录轮次，不设最多两轮。修复有进展时继续复审；任务完成后，后续修改按实际影响重新判断审查要求。同一未完成任务不得通过改名、拆分或换会话清除待解决问题。

已触发 Gate 的任务，最终候选须获得独立 `pass`。交付前候选内容变化会使原结论失效，包括 minor 修复；记录目标路径、候选 SHA-256、实际 reviewer 调用标识与原始结果，并验证交付内容与已审候选一致。通过、交付并验证一致后关闭本次任务；后续真实错字等低影响修改可自审，改变事实、判断或结构时重新独立审查。审查记录无法恢复时，注明缺失并重新审查当前候选，不推定历史通过。

缺少关键事实或授权、独立审查能力不可用，或连续两次修复后同一关键问题仍无实质进展时，暂停并说明阻塞和解除条件；可自行查证或调整方法时先处理。阻塞解除后继续修复与审查，不能因次数用完永久锁住文章，也不能将恢复视为通过。
