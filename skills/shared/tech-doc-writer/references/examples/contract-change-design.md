# 一、背景

资源需要支持**上架状态**，以统一多种资源的管理方式。

**需求来源：** 本例已省略原需求链接；实际文档关联当前确认的需求。

# 二、数据结构设计

## 2.1 数据结构定义

本例省略完整结构定义，仅保留一致性约束和变更摘要。实际文档需给出新增或实质变化的结构及事件载荷定义；完全复用的结构引用权威 Schema。

非公开资源外层状态与加密正文中的同名字段必须一致，由所属服务生成一致内容，合约只整体存储并原样发送事件。

## 2.2 变更说明

| 类型、字段 | 变更类型 | 变更内容 |
|---|---|---|
| **EntryInfo.ListingStatus** | 新增 | 取值为已上架或已下架，合约上无草稿状态。 |
| **EntryUnpublishedEvent** | 新增 | 携带下架后的完整资源对象。 |

# 三、合约方法设计

## 3.1 方法定义

上架方法接收完整资源对象，并返回执行错误。

```go
PublishEntry(entry *types.EntryInfo) error
UnpublishEntry(entry *types.EntryInfo) error
DeleteEntry(number string, sequence int) error
```

## 3.2 变更说明

| 合约方法 | 变更类型 | 变更说明 | 事件 |
|---|---|---|---|
| **CreateEntry → PublishEntry** | 重命名 + 语义调整 | 首次上架或重新上架时可重新选择可见范围；已上架资源仅允许扩大可见范围。 | **EntryPublishedEvent**，携带完整资源。 |
| **UnpublishEntry** | 新增 | 接收完整资源，仅允许已上架转为已下架并整体覆盖链上数据。 | **EntryUnpublishedEvent**，携带完整资源。 |
| **DeleteEntry** | 修改 | 仅允许删除已下架资源，不保留已删除状态。 | **EntryDeletedEvent**，携带资源标识。 |
